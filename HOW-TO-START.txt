DL TERRAIN SLICER - HOW TO START FROM THE SOURCE CODE
=====================================================

This is for running the app from its source code, which needs Python.
Most people want the packaged download instead, which needs nothing:
see README.md, "Getting started".

The app runs locally on your computer. No internet needed.


OPTION 1 - DOUBLE-CLICK (easiest)
---------------------------------
1. Open the project folder (the one this file is in).
2. Double-click:     start.bat
   - A console window opens. It is the app's engine - keep it open.
   - Your browser opens the app by itself, on port 8765 - or on the next
     free port if 8765 is taken, so a second copy never fights the first.
3. To STOP the app: close the console window
   (or press Ctrl+C inside it)


OPTION 2 - FROM POWERSHELL / A TERMINAL
---------------------------------------
1. Open PowerShell in the project folder.
2. Run:

   .venv\Scripts\python.exe launcher.py

   Options: --port 9000 insists on one port, --no-browser does not open
   a browser window.
3. To STOP: press Ctrl+C in the PowerShell window


USING THE APP
-------------
- The menu on the left runs top to bottom: Import, Slice, Nest, Label,
  Engrave, Export - one section open at a time. Drag it by its header;
  the button at the top right (or Esc) folds it away and back.
- Drop a terrain into Import: GeoTIFF (.tif), ASCII grid (.asc), or an
  OBJ / STL mesh - or click "load demo terrain" to try it out.
- Optionally add vector files in Engrave - shapefile, DXF (e.g. drawn
  in Rhino), GeoJSON, GML or GeoPackage: areas become hatched areas,
  lines become scored linework, points become circles.
- Adjust parameters; the preview updates live.
- "Export DXF (ZIP)" downloads one DXF per material sheet plus a
  cutting_report.txt with assembly notes.


IF IT DOES NOT START
--------------------
- ".venv missing" (e.g. after copying the folder to a new machine):
  open PowerShell in the project folder and run once:

     python -m venv .venv
     .venv\Scripts\pip install -r requirements.txt

  (if a package is missing for your Python version, use
   py -3.12 -m venv .venv instead of the first line)
  then start normally as above.
- The page looks broken after an update: hard-refresh with Ctrl+F5.
