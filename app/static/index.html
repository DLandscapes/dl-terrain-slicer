The first start takes 20–60 seconds — on an older computer up to a couple of minutes. That is normal: the whole Python engine is being downloaded (about 20 MB) and compiled inside your browser. It is cached afterwards, so the next visit starts in a few seconds.
Everything runs on your own machine — your terrain files are never uploaded anywhere.
